## Phase Checks

| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Import `genoio` and inspect public API names. | Public names are present; no reference packages are imported as side effects. |
| 2 | Open VCF, PLINK1, and PLINK2 fixture-style paths. | VCF/PLINK1 resolve; PLINK2 resolves but read decode reports deferred support. |
| 3 | Call `samples()` and `variants()` on VCF and PLINK1 fixtures. | Polars frames preserve source order and normalized columns. |
| 4 | Read dense VCF and PLINK1 genotypes with `return_samples` and `return_variants`. | Matrix is samples x variants, values count A1, metadata axes align. |
| 5 | Exercise `missing="nan"`, `"raise"`, and `"impute"`. | Missing policy behavior matches documented contract; invalid integer/missing combinations fail. |
| 6 | Apply `chrom`, `region`, `id_in`, `snp`, `biallelic`, `maf`, `mac`, `missing_rate`, and `polymorphic`. | Returned matrix columns and variant metadata match hand/reference expectations. |
| 7 | Iterate blocks with size smaller than variant count. | Block shapes honor size; concatenated blocks equal full read. |
| 8 | Read sparse CSC and CSR. | Sparse matrices reconstruct dense results after accounting for sparse allele flipping; missing sparse data raises. |
| 9 | Read `kind="haplo"` from phased and unphased sources. | Phased VCF returns haplotype rows; PLINK1/unphased VCF raise `UnsupportedRepresentation`. |

## End-to-End Scenarios

| Scenario | Steps | Expected Result |
|----------|-------|-----------------|
| Dense filtered read | Open VCF, read with `variants=genoio.snp() & genoio.maf(min=0.1)` and metadata. | Retained variants match reference filter; genotype columns align to metadata. |
| Block parity | Read full dense matrix, then concatenate `blocks(size=2)`. | Concatenated matrix equals full read exactly. |
| Sparse parity | Read dense and sparse on no-missing fixture, convert sparse to dense with returned flip metadata. | Reconstructed sparse result equals dense source dosage. |
| Haplotype gate | Read PLINK1 and unphased VCF with `kind="haplo"`, then phased VCF. | Unsupported sources fail; phased VCF returns deterministic haplotype row order. |
